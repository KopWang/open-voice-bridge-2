遥控快捷桥 0.1.4-test.6
=========================

用途
----

本应用把 Xiaomi RC003 遥控器的按键映射为 Mac 快捷键。
默认语音键映射为 Control + Option，用于触发 Typeless。
录音仍由 Typeless 直接读取 DJI Mic Mini。

应用不读取遥控器麦克风、不处理音频、不修改系统录音设备，也不需要虚拟音频驱动。

安装
----

1. 把“遥控快捷桥.app”拖到旁边的 Applications。
2. 从“应用程序”打开“遥控快捷桥”。
3. 如果 macOS 阻止打开，在“系统设置 -> 隐私与安全性”中选择“仍要打开”。

这是本机自签名、未公证的测试版，不是 Developer ID 正式发行版。

配对
----

1. 打开 macOS 蓝牙设置。
2. 同时长按 RC003 的主页键和菜单键，进入配对状态。
3. 在 macOS 中完成遥控器配对。

权限
----

在应用设置中依次打开：

1. 输入监控
2. 辅助功能

返回应用后点击右上角的重新连接按钮。应用不需要麦克风权限或应用级蓝牙权限。

Typeless
--------

1. 保持 Typeless 使用 DJI Mic Mini 作为麦克风。
2. 把 Typeless 的语音输入快捷键设置为 Control + Option。
3. 按一下 RC003 语音键开始输入。
4. 再按一下 RC003 语音键结束输入。

默认菜单键是可保持的 Control。按住菜单键再按方向键，可使用
Control + 上/下/左/右。

如需其他组合，在应用中点击对应按键的“重新录制”；也可以点击
键盘图标，直接把遥控器按键设为 Control、Option、Shift 或 Command。

“组合按键”区域可以把两个共同按下的遥控器按键映射为另一个输出。
RC003 会串行上报共同按下的键；应用会对已配置组合的成员使用 500ms
识别窗口，输出仍按真实键盘的按下/释放状态发送。

卸载
----

退出应用后删除“应用程序/遥控快捷桥.app”。登录启动可在应用内关闭，也可在 macOS 登录项中移除。
